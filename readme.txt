BG_ALPHA_STUDIO_1.11
====================

【1.11の修正（1.10の起動エラー対策）】
・1.10で「module tkinterdnd2.TkinterDnD has no attribute require」と表示されて
  D&D初期化に失敗する不具合を修正しました。
・TkinterDnD._require()でTkDnDを読み込み、CustomTkinterのルートに
  DnDWrapperを継承させて各ウィジェットのD&D登録を可能にしました。
・D&Dイベントの登録に失敗した場合、例外の内容をダイアログで表示します。
・1.10で追加したD&D読み込みと縦横比のログ表示を維持しています。

【1.10以降の主な機能】
・Windowsエクスプローラーから動画（MP4 / MOV / MKV / AVI / WEBM / M4V）をドラッグ＆ドロップできます。
・「変換元の動画」の入力欄と、直下の専用ドロップ欄で受け付けます。
・複数ファイルを同時に落とした場合は最初の対応動画を読み込み、ログに通知します。
・「動画を選択」ボタンも従来どおり使えます。
・D&D / ファイルダイアログ / パスの貼り付けのいずれも、動画読み込み後に
  元動画の横×縦ピクセル数と縦横比をログに表示します。
  例：入力アスペクト：16:9（1920×1080 px / 横長）
      入力アスペクト：9:16（1080×1920 px / 縦長）
・正確な比率（最大公約数で約分）を表示。SAR等によって表示アスペクト(DAR)
  が異なる場合はDARも併記します。回転メタデータがあれば併記します。
・縦横比はFFmpegを使用し、重い動画でもUIを止めないよう別スレッドで取得します。
・PNG抽出 → Photoshop背景除去 → 透過MOV化 の処理は従来どおりです。

【実行方法】
1. 開発用 .pyw を動かすPCでは、install_dependencies.bat を実行します。
   またはコマンドプロンプトで python -m pip install -r requirements.txt。
   CustomTkinterに加えてTkinterDnD2が必要です。
2. FFmpegがPATH、またはプログラムと同じフォルダーなどで見つかる状態にします。
3. bg_alpha_studio_1.11.pyw をダブルクリックします。
4. 専用ドロップ欄に動画を落とすか「動画を選択」から動画を読み込みます。
5. 処理状況 / ログに縦横比が表示されるのを確認します。
6. 保存先を指定して「一括変換を開始」を押します。

【EXE化】
・build_exe.bat を実行すると、フォルダー内の唯一の bg_alpha_studio_*.pyw を
  自動検出し、dist\bg_alpha_studio_1.11.exe を生成します。
・最新版のTkinterDnD2を組み込み、TkDnDのバイナリもPyInstallerで同梱します。
・EXE実行PCにはPythonは不要です。ただしAdobe Photoshopが必要です。
・EXEを再ビルドする際は、FFmpegも自動検出または同階層に配置してください。
・本ZIPには旧1.0のEXEは含めていません。旧EXEを使うと修正前の動作になります。

【注意】
・WindowsエクスプローラーからのD&Dが無効な場合は、アプリを管理者として
  実行していないか確認してください。権限差によりWindowsがドロップを制限することがあります。
・FFmpegがない場合、縦横比は解析できません。ファイル選択は可能です。
・動画の回転メタデータによる表示向きと、フレームの格納向きは一致しない場合があります。
・PNG連番、JSX、生成MOVは従来どおり保存します。

【1.11の検証と制限】
・Python構文チェック、ソース中の正しいAPI呼び出しを確認。
・FFmpegによる動画アスペクト解析の動作確認。
・こちらはWindowsではないため、Explorerからの実D&DおよびPhotoshop連携は
  Windows 11実機で確認が必要です。

【動作確認】
・Python構文チェック済み。
・FFmpegで作った日本語名・空白入りの3種類のダミー動画（16:9、9:16、1:1）で
  縦横比解析・ログ書式を確認済み。
・WindowsのGUI操作、Explorerからの実ドラッグ＆ドロップ、およびPhotoshopの
  通し動作はこの環境では未検証です。
